# 컵 섞기 🥤

공이 든 컵을 눈으로 따라가는 야바위 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: 섞기가 끝나면 **공이 든 컵을 누릅니다**(폰은 톡, PC 는 클릭 또는 숫자 `1`~`6` 키). `P` 일시정지, `M` 소리. 창이 가려지면 저절로 일시정지합니다.
- 규칙은 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙
- 한 라운드는 ① 공 보여 주기(1.4초) → ② 컵 내리기(0.5초) → ③ 섞기 → ④ 고르기 → ⑤ 결과(1.7초). 섞기는 두 컵이 자리를 바꾸는 것을 여러 번 하고, 한 컵은 앞으로 한 컵은 뒤로 호를 그리며 움직입니다. 공이 한 번도 안 움직이는 라운드가 없게 만들었습니다(공이 든 컵이 최소 2번은 바뀜).
- **라운드가 오를수록** 컵이 늘고(쉬움 3 → 4(4라운드부터) → 5(9라운드부터), 보통 3 → 4(3) → 5(5) → 6(9)), 섞는 횟수가 늘고, 한 번 섞는 시간이 줄고(쉬움 0.62 → 0.32초, 보통 0.5 → 0.2초), 두 쌍이 **동시에** 섞이기도 합니다(쉬움 6라운드부터 20%, 보통 3라운드부터 30%).
- 맞히면 다음 라운드(점수 = 10 × 라운드 + 5 × 연속 정답 수). 틀리면 ❤ 가 줄고 **같은 라운드를 다시** 합니다. ❤ 가 0 이 되면 끝. 쉬움은 ❤ 3개·시간 제한 없음, 보통은 ❤ 2개이고 고르는 시간 8초(넘기면 틀린 것).
- 기록은 **보통에서 성공한 라운드 수**입니다(쉬움은 저장 안 함). 맞힐 때마다 바로 저장합니다.

## 만든 방식
- 섞기 전체를 라운드 시작 때 미리 정해 두고(`swaps`), 화면은 시간에 따라 그 진행도(`si`, `swapT`)로 그림만 그립니다. 그래서 시험에서 **미리 계산한 공 위치와 실제로 섞은 결과가 같은지**, 칸이 항상 순열인지, 한 번에 큰 시간(12초)을 넘겨도 작은 걸음과 결과가 같은지 확인합니다.
- 컵 수 · 속도 · 섞는 횟수는 제가 정한 값이고, 사람이 실제로 몇 라운드까지 갈 수 있는지(체감 난이도)는 **측정하지 못했습니다**. 온라인 대전은 없습니다.
